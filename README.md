# MYBOT247 website

Static site for mybot247.com (WhatsApp bots for businesses).

- `index.html`: Hebrew (default, RTL)
- `en/index.html`: English
- `assets/hero-loop.mp4`: background video for the top section (add it, muted MP4, under 3 MB). If missing, the page shows an animated gradient instead.

No build step. To update the live site: commit and push, then on the server run `git pull` inside the site folder.
